## Data

**Recovered CPS March Supplement Work Disability Variables, 1981–1987**

The CPS March Supplement has asked about work disability since 1981, but these variables are missing from standard public sources (IPUMS, NBER) for years prior to 1988. These files were shared by Andrew Houtenville (University of New Hampshire). See the documentation for variable descriptions and merge instructions for both NBER and IPUMS public extracts.

[Documentation (PDF)](/files/CPS_March_Supplement_1981-87_Disability_Variables.pdf) &middot; [Data (.dta)](/files/cps_disability_1981-87.dta)

I have also written a Center for Economic Studies (CES) Technical Note describing the process to bring these data into the FSRDC environment for researchers working with the 1981-87 CPS. The abstract can be found [here](https://ideas.repec.org/p/cen/tnotes/26-24.html), and the full report as well as code can be requested by researchers who have approved projects in the RDC.
