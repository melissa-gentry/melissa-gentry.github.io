## Data

**Recovered CPS March Supplement Work Disability Variables, 1981–1987**

The CPS March Supplement has asked about work disability since 1981, but these variables are missing from standard public sources (IPUMS, NBER) for years prior to 1988. These files were shared by Andrew Houtenville (University of New Hampshire). See the documentation for variable descriptions and merge instructions for both NBER and IPUMS extracts.
